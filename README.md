
# About Project
A hobby project leveraging Kafka to process financial payment transactions with exactly-once-semantics and writing results to a PostgreSQL database. Consumption and processing in the Consumer is decoupled via a worker-thread architecture. The main thread handles polling and offset commits whilst the worker handles batch processing and database writes. Thread lifecycle is managed manually rather than via Java's `Executor Service` as a deliberate choice to build a first principles understanding of Java concurrency, thread-state transitions and cross-thread visibility guarantees.
